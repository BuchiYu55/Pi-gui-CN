欢迎使用 Pi 桌面版

开始前需要连接一个 AI 模型服务（自带 API Key，用多少付多少）。
整个过程约 2 分钟，配置随时可在设置中心修改。

🖥 本地优先
会话与文件都在你自己的电脑上，不经过第三方服务器
🔀 多模型切换
一个界面随时切换智谱 / DeepSeek / Kimi / OpenRouter 等服务
✅ 任务可视化
文件树、任务清单、浏览器面板，coding agent 全程看得见

选择模型服务商

推荐国内服务商：人民币直付、无需外币信用卡。随时可以再添加其他家。

获取 API Key

按下面三步拿到密钥：

↗ 打开注册页面

🔒 Key 只保存在你自己电脑的 ~/.pi/agent/models.json，不会上传到任何地方。计费由服务商直接管理，本应用不经手任何费用。

粘贴 API Key 并验证

粘贴后点「测试连接」——只查询一次模型列表（零 token 消耗），不会产生费用。

👁

💡 常见问题：Key 前后多了空格（自动去除）、账户欠费、服务商平台未开通对应模型。

选择默认模型

新会话将默认使用它。之后可随时在 设置 → 模型与提供商 里改。

✓

配置完成！

配置已写入 ~/.pi/agent/（models.json + settings.json）· 免重启即时生效
场景三档（工作 / 深想 / 日常）已按此模型就绪，点击输入框下方即可切换
